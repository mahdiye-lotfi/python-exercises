# ATM Simulator

A beginner-friendly Python terminal project that simulates a simple ATM.

## Features

- PIN authentication with up to 3 attempts
- Check account balance
- Withdraw money
- Deposit money
- Exit the program
- Basic input and amount checks

## Requirements

- Python 3

## Run

```bash
python main.py
```

## Default PIN

`1234`

## Starting balance

`1,000,000 Toman`

## Concepts practiced

- Variables
- `input()` and `print()`
- Type conversion with `int()`
- `if`, `elif`, and `else`
- `while` loops
- `break`
- Arithmetic operators
